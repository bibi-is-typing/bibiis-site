    실제 사례식당 앱 새 버전. 얼굴만 누르면 출근, 사장님은 이상한 기록만 확인.

    • 검증하고 덜어내며 키우기

    실제 사례여러 법인이 매일 쓰는 근태·결재 플랫폼. 검증 후 다시 만든 PRIA.

      궁금한 것

      정말 서버비가 안 드나요?

      작은 매장·팀 규모라면 대부분 구글 시트, 앱스 스크립트, 슬랙·텔레그램처럼 이미 쓰는 도구 안에서 돌아가게 만들어요. 규모가 커져 별도 서버가 필요해지면 미리 말씀드리고 비용을 같이 정해요.

      AI로 만드세요?

      네. Claude Code 같은 AI 도구로 빠르게 만들고, 무엇을 만들지 정하는 기획과 검수는 직접 합니다.

      알림은 어디로 받나요?

      슬랙이나 텔레그램처럼 이미 쓰는 메신저로 받아요. 카카오톡은 비즈니스 채널(알림톡)로만 자동 발송이 가능해서, 사업자 채널과 문구 심사가 필요하고 건당 비용이 들어요. 필요하면 같이 준비해 드려요.

      코드와 계정은 누구 소유인가요?

      처음부터 맡기신 분 이름으로 만듭니다. 제가 없어도 그대로 돌아가고, 다른 개발자에게 넘겨도 이어서 쓸 수 있어요.

      시안이 마음에 안 들면요?

      48시간 시안까지는 비용 없이 그만두실 수 있어요.
