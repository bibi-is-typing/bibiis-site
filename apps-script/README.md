# 상담 폼 연결하기 (10분)

1. 브랜드용 구글 계정으로 새 구글 시트를 만들어요. 이름: `bibiis 상담`
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 기본 코드를 지우고 이 폴더의 `Code.gs` 내용을 붙여 넣어요.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: 나
   - 액세스 권한: 모든 사용자
5. 권한 승인 창이 뜨면 허용해요. (시트에 쓰기, 메일 보내기 권한)
6. 나온 **웹 앱 URL**을 `assets/js/config.js`의 `formEndpoint`에 붙여 넣어요.
7. 왼쪽 **트리거(시계 아이콘) → 트리거 추가**: 함수 `purgeOld`, 시간 기반, 매일. 3개월 지난 미계약 상담을 자동으로 지워요.
8. 상담이 계약으로 이어지면 시트의 `상태` 칸을 `계약`으로 바꿔 두세요. 그 줄은 지우지 않아요.

`formEndpoint`가 비어 있는 동안에는, 폼에서 "보내기"를 누르면 메일 앱이 열리고 내용이 hello@bibiis.ai로 채워져요.
